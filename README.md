# BuildMate

Современный веб-сайт на FastAPI с интерактивным калькулятором стоимости строительства дома и системой распознавания мебели на фотографиях.

## Функциональность

- Калькулятор стоимости строительства дома с учетом различных параметров:
  - Площадь дома
  - Тип фундамента
  - Материал стен
  - Количество этажей
  - Тип кровли и конструкции
  - Межэтажные перекрытия (сборные железобетонные плиты и монолитные железобетонные)
  - Дополнительные опции (гараж, терраса, подвал и др.)
- ИИ-рекомендации по оптимизации строительства на основе введенных параметров
- Распознавание мебели на фотографиях с использованием компьютерного зрения
- Детализированный расчет материалов с актуальными ценами (обновлено в мае 2025)
- Адаптивный интерфейс с поддержкой темной темы
- Быстрая и отзывчивая работа на мобильных устройствах

## Технический стек

### Backend
- FastAPI
- Pydantic + Shapely (расчёт геометрии)
- PyTorch (для модели распознавания мебели)
- Uvicorn

### Frontend
- React 18 + TypeScript + Vite
- Zustand (управление состоянием)
- Fabric.js (рисование плана дома на canvas)
- Поддержка тёмной/светлой темы

## Установка и запуск

Требования: Python 3.11+, Node.js 18+, npm 9+.

1. Клонируйте репозиторий:
```
git clone https://github.com/yourusername/BuildMate.git
cd BuildMate
```

2. Создайте и активируйте виртуальное окружение:
```
python -m venv venv311
source venv311/bin/activate  # На Windows: venv311\Scripts\activate
```

3. Установите Python-зависимости:
```
pip install -r requirements.txt
```

4. Установите и соберите фронтенд:
```
cd frontend
npm install
npm run build
cd ..
```

Команда `npm run build` запускает `tsc -b` (проверка типов) и затем `vite build` — результат кладётся в `app/static/react/`, откуда FastAPI раздаёт его как статику.

При разработке фронтенда используйте:
```
cd frontend
npm run dev
```

Vite запустит dev-сервер на `localhost:5173` с горячей перезагрузкой и проксированием API-запросов на `localhost:8000`.

5. Запустите сервер:
```
python main.py
```

6. Откройте в браузере: http://localhost:8000

## API Endpoints

- `POST /api/v2/geometry/compute` — геометрия: периметр, площадь застройки, метрики стен, помещения
- `POST /api/v2/materials/calculate` — полная смета материалов
- `GET  /api/v2/materials` — каталог материалов и цен
- `/api/recommendations` — ИИ-рекомендации
- `/api/recognize-furniture` — распознавание мебели

## Модель распознавания мебели

В проекте используется предобученная и дообученная модель ResNet18 для распознавания типов мебели на фотографиях. Модель сохранена в файле `Super_model.pth`.

## Актуальные цены на материалы

Все цены в калькуляторе обновлены по состоянию на май 2025 года и соответствуют средним рыночным ценам в России. База данных материалов включает:

- Фундамент (ленточный, свайный, плитный, столбчатый)
- Стены (кирпич, дерево, блоки, монолит, панели)
- Кровля (металлочерепица, керамическая черепица, гибкая черепица, шифер, плоская кровля)
- Межэтажные перекрытия (сборные ж/б плиты, монолитные ж/б)
- Гидроизоляционные материалы
- Герметики и монтажные материалы
